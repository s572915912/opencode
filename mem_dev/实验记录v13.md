## 一、实现方向

V13 受 xMemory 论文启发，在 compaction prompt 层面做了 3 项改进，不涉及代码逻辑变更：

1. **PK 4 重质量过滤**：确保只保留高价值、持久性知识
2. **Prediction-Correction SK 提取**：只提取相对于已有 PK 的"增量信息"
3. **事件时序增强**：强化因果依赖和时间顺序保留

## 三、改动 1：PK 4-Test Quality Filter

在 PK 段新增质量过滤指令，每条 PK 必须通过 4 项测试：

```
For each PK entry, apply this 4-test quality filter:
1. Persistence: Will this still be relevant 10 conversation turns from now?
2. Specificity: Does this contain an EXACT value, name, or identifier?
3. Utility: Would losing this information cause a wrong answer to a future question?
4. Independence: Is this information NOT derivable from other PK entries?

Only keep entries that pass ALL 4 tests.
```

**目的**：减少 PK 中的噪声条目，只保留真正重要的信息。

---

## 四、改动 2：Prediction-Correction SK 提取

将原有的 Knowledge Gap Analysis 重写为 3 步提取法：

```
## Knowledge Gap Analysis (Prediction-Correction)

Use this 3-step method:
1. PREDICT: Before reading the conversation, list what you'd expect based on PK
2. COMPARE: Read the ORIGINAL conversation and find what CONTRADICTS or is MISSING
3. EXTRACT: Only extract information that SURPRISED you (was missing or wrong)
```

**原理**：V12 的 SK 提取是"提取所有新信息"，容易产生冗余。V13 改为"只提取 surprise"——相对于 PK 预期的差异部分。灵感来自 xMemory 的 Prediction-Correction 机制。

---

## 五、改动 3：事件时序增强

在 Chronological Event Log 段落增加时序保留指令：

```
### Chronological Event Log (CRITICAL for temporal reasoning)
Maintain EXACT temporal ordering. For each entry:
- Include causal dependencies: "X happened BECAUSE of Y"
- Note sequence: "FIRST did A, THEN did B, FINALLY did C"
- Preserve time gaps: "3 days after X, user did Y"
```

同时在 SK 提取中新增 `[TEMPORAL]` 标签：

```
- [TEMPORAL] event_A happened BEFORE event_B (gap: N days)
```

**目的**：针对 V12 中 event_ordering 始终 0% 的问题，在 prompt 层面强化时序保留。

## 七、分析

### 核心收益

1. **information_extraction +10pp**：Prediction-Correction 方法让模型聚焦于保留精确值（版本号、端口、配置），减少了"模糊化"现象
2. **event_ordering 首次得分 10%**：时序增强 prompt 使模型在 1M C3 上达到 tau=1.0（完美排序）
3. **multi_session_reasoning +5.4pp**：质量过滤保留的 PK 条目质量更高，跨会话推理更准确
4. **abstention +17.5pp**：模型更好地识别了"信息不存在"的场景

### 主要损失

1. **knowledge_update -15pp**：Independence 测试过于严格，部分更新值被过滤（如 "inference_time 从 45ms 更新为 38ms" 被认为可从其他条目推导）
2. **temporal_reasoning -2.5pp**：意外。可能因为质量过滤丢弃了部分日期信息
